# artinscience · brand

**artinscience** is generative pen-plotter art. Each piece starts as data about
the world — how a place changed over two hundred years, the lie of the land, the
sky on a given night — and ends as ink on paper, drawn by machine and finished
by hand. The physical plate is the product; the code is the reproducible
process behind it.

The work is told in serial **chapters and volumes**: a place, a subject or a
line of inquiry, taken one plate at a time.

## Aesthetic lines

- **Industrial / data-cartography**: places in data.
- **Mythic / ancient-script**: cultures in their own writing.
- **Scholarly / manuscript**: knowledge, hatch-shaded and Latin-labelled.
- *Architecture*, *machines* and the *cosmos* span all three: the precise
  drawing, the figure, the engraved plate.

## Product tiers

- **Premium**: unique pen-plotted plates, made slowly and in low volume.
- **Commodity**: puzzle and activity books, drawn by the same machine.

## See the work

Rendered plates are in the

rendering is a preview; the plate is the piece.

## The record

Every plate is backed by a private system of record: the sources and their
licences, the plot sessions, the pens and paper, and the sales.
[LEDGER_ANCHORS.md](LEDGER_ANCHORS.md) publishes a digest of that record at
intervals, so its history can be checked against this repository's.

## What is public here, and what is not

The process is private and the artifact is public. This repository carries the
brand and the ledger anchors; the engine, the recipes, the research and the
strategy stay private.

## Pull requests

Every pull request that changes anything other than Markdown must also update
the docs, even minimally. The `docs` check
([`.github/workflows/docs.yml`](.github/workflows/docs.yml)) enforces that, and
that every path, link and image the docs name still resolves. A pull request
that changes only docs is labelled `human-review`.
